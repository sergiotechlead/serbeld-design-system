# Icons

Font Awesome 6 Free (Icons: CC BY 4.0), copied from serbeld.space's inline SVG; the three brand glyphs come from Font Awesome Free Brands 6.7.2.

Files ship in a single ink, #a3a3ab (`color-text-muted`), so they preview on any ground. When inlining, set `fill="currentColor"` — the `Icon` component does this — so the icon inherits the colour of the text beside it.

- `fa-bars` — mobile navigation toggle
- `fa-download` — Download CV, primary hero action
- `fa-arrow-right` — Get in touch, outline hero action
- `fa-calendar-days` — Schedule a call, contact section
- `fa-check` — Also working with, capability list
- `fa-arrow-up-right-from-square` — View credential (external link)
- `fa-brand-instagram`, `fa-brand-github`, `fa-brand-linkedin` — the social cluster, always in that order

13px inside buttons, 1em elsewhere, 24px for social glyphs. Do not mix icon sets.
