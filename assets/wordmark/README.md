# Wordmark

The name set in Poppins SemiBold 600, outlined from the font with its own kerning, tracking zero; clear space of half the cap height is built into every viewBox.

- `sergio-beleno-wordmark.svg` — primary. Ink #e7e7ea (`color-text`) for `color-bg` and `color-surface`.
- `sergio-beleno-wordmark-on-accent.svg` — primary on a solid Signal Blue field. Ink #0f0f0f (`color-text-on-accent`).
- `sergio-beleno-lockup.svg` — name over "Technical Lead (VTEX)" (Poppins 500, ink #a3a3ab) for profiles and proposal covers, on dark grounds.
- `sb-monogram.svg` / `sb-monogram-on-accent.svg` — "SB", for avatars and favicons only, at 32px and below. Inks #e7e7ea and #0f0f0f.

Minimum 14px tall on screen (the tilde loses definition below), 22mm wide in print. Never recolour in the accent, never add effects, never place over a photograph without a solid panel.
