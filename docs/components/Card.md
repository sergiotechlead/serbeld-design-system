# Card

The one card shell every card shares: `color-surface`, a 1px `color-border` hairline, `radius-md`, 24px padding. `interactive` raises the border to `color-border-strong` on hover (0.2s ease).

**Provide:** optional `title` (`card-title`), `subtitle` (Lekton 14px muted) and `children`. Use it for contact panels and any new grouping before inventing a new surface.
