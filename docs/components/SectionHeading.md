# SectionHeading

Every section opens with the same three-part heading: a two-digit `color-accent` index, the title in Poppins 26px 600 (`section-heading`), and a hairline that fills the remaining width, 12px apart and 32px above the content.

**Provide:** `index` (a number gets its leading zero), `children` (the title) and `id`, which the section references with `aria-labelledby`.

- Do: number sections in document order: 01 About, 02 Experience, 03 Education & Credentials, 04 Skills, 05 Services, 06 Contact.
- Don't: skip heading levels; the hero name is the only h1, sections are h2.
