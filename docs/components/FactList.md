# FactList

The About facts block: label and value pairs on a `color-surface` card with hairline separators, sitting beside the bio in a 1.4fr / 1fr grid (`.sb-about`) that collapses to one column at 820px.

**Provide:** `facts` — Residence, Freelance, Specialty, Focus. Update Residence on relocation; switch Freelance to Selective or Booked as capacity changes.

**Spec:** assembled from existing styles: label in `meta` (`color-text-faint`), value in Poppins 14px 500 `color-text`.

- Don't: state an age in years anywhere near it; derive it from a birth date field or remove it.
