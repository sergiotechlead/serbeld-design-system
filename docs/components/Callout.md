# Callout

The brand manual's note block for documents (manuals, proposals, capability decks): a `color-surface` panel with a 3px left rule, an uppercase Poppins label, and Lekton body copy.

**Provide:** `label` (POSITIONING, TOUCH TARGET, RULE), `children`, and `tone` — `accent` (default) for guidance, `warning` for rules and risks. The warning label is set in `color-text` beside the `color-warning` rule, because `color-warning` as 13px text is only 3.53:1 on `color-surface`.

- Don't: use it on the website; on the site, information sits in cards and sections.
