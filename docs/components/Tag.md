# Tag

A pill for short labels: `chip` (Poppins 13px 500, `color-accent` on `color-accent-soft` with a `color-accent-shadow` border) for personality, topic and capability lists, and `badge` (12px 600 uppercase, letter-spacing 0.08em) for status such as Current.

**Provide:** one to three words as `children`; wrap a set in `<ul class="sb-tag-list">`.

- Do: let the word carry the meaning; the colour only confirms it.
- Don't: use tags as buttons, or mark more than one timeline entry Current.
